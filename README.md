# 🏋️ Iron Fitness Gym Management System

A complete Gym Management Web Application built using Python Flask to manage members, trainers, and membership plans efficiently.

### 📂 Project Repository: Gym Management System

### ✨ Features
- **Dashboard:** View total members, trainers, monthly income and active plans
- **Member Management:** Add, Edit, Delete and Search gym members
- **Trainer Management:** Manage trainers and their specializations
- **Plan Management:** Create and manage monthly/yearly membership plans
- **Responsive UI:** Clean and modern UI using Bootstrap 5

### 🛠️ Tech Stack Used
- **Backend:** Python, Flask
- **Database:** SQLite3
- **Frontend:** HTML, CSS, Bootstrap 5, Jinja2 Templates
- **Version Control:** Git & GitHub
